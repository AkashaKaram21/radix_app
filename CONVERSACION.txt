Exploro la app iOS (Expo / React Native + TypeScript) para
entender qué hace:

- Stack iOS: Expo SDK 54, expo-router, React Native 0.81, TS.
- Backend: https://api.raddix.pro/v1/ (prod) o
  http://localhost:8080/v2/ (dev). Auth con Bearer token en
  expo-secure-store.
- Pantallas: Splash, Login, Recover, Onboarding (theme gate),
  ChangePassword, FamilyLogin, FamilyDashboard, MainTabs
  (Dashboard, Treatment, Health, Alerts, Settings, Watch,
  Profile, etc.).
- DESIGN.md: paletas "Radix Health Dual UI System 3.0.0"
  light=Soft UI / dark=Neon Tech, cards 24dp, inputs 12dp,
  botones primarios píldora, valores clínicos sin fallback.

Consulto los apuntes davidfs-itic/Android — usa:
- Kotlin (no Java)
- Layouts XML (no Jetpack Compose)
- MVVM (ViewModel + Observer)
- Retrofit para HTTP
- DataStore Preferences para persistencia
- Glide para imágenes
- MPAndroidChart para gráficos

El crash es porque splash_background usaba
"?android:colorBackground" — referencia a atributo del tema
que no se puede resolver cuando el drawable se infla como
windowBackground (antes de aplicar el tema).

Fix:
  • drawable/splash_background.xml ahora usa color literal
    @color/background_light + ic_launcher_foreground.
  • Nuevo drawable-night/splash_background.xml con
    @color/background_dark para el modo oscuro.
  • Quitados android:width/height inline del <item>.

Instrucciones: Build → Clean Project → Run ▶. Si sigue
crasheando, desinstalar la app del emulador y reinstalar.
